## 3. 추론 (S2) — 설계는 지금 고정, 실행은 1b 결정 후 (또는 두 대조군 변형 모두)

- **3a. 추정대상 동일성**
  - 비교할 절차는 모두 같은 θ, 즉 같은 셀과 같은 가중치를 추정해야 한다.
    - θ = (1/10) Σ_{e=0..9} (1/N_e) Σ_{i∈I_e} δ̂_{i,e}
  - 후보별 확인 방법:
    - (i) 현행 점수 곱 bootstrap: 정의상 같다.
    - (ii) 품목별 평균 대조값 δ̄_i = (1/10) Σ_e δ̂_{i,e}의 평균: 7개 품목이 모든 e에서 관측될 때만 θ와 같다. 수치로 확인한다.
    - (iii) 차분누적(stacked) 회귀의 WCR: 계수가 θ와 수치적으로(1e-10) 같도록 가중치를 구성할 수 있을 때만 후보로 둔다. 그렇지 않으면 다른 추정대상으로 보고 비교에서 제외한다.
- **3b. 이론적 적용 조건** (모의실험 전에 이 파일로 판단)

| 절차 | 적용 조건 | 이 자료에서의 판단 |
|---|---|---|
| 현행 점수 bootstrap | 기여 군집이 많고 각 군집의 기여가 작음 | 처리 7개가 분산을 지배하므로 조건이 약함 |
| (ii) 7개 품목 대조값의 t(6) | 품목 대조값이 독립·등분산 | 공유 대조군 평균 때문에 독립성이 성립하지 않음. 근사로만 사용 |
| (iii) WCR | 처리군집 수가 충분함 | 문헌상 처리군집이 적을 때 보수적 경향(서지 확인 필요) |
| 결론 | — | 어느 절차도 이론적으로 충분히 뒷받침되지 않는다. 따라서 **자동 선택을 하지 않는다.** |

- **3c. 모의실험의 역할: 취약성 점검이지 선택 장치가 아니다.**
  - 조건 격자(사전 고정):
    - 품목별 오차분산: clean 셀 TWFE 잔차분산
    - 품목별 AR(1): clean 셀 잔차로 추정
    - 작물군 내 상관 ρ ∈ {0, 0.3, 0.6}
    - 효과 0
    - 관측 셀 구조: 현 표본
  - 반복 4,000회. 명목 5%에서 몬테카를로 SE는 약 0.34%p다.
  - 판정 기준(사전 고정): 기각률의 몬테카를로 95% 구간이 [2.5%, 7.5%]와 겹치면 "그 조건에서 반증되지 않음"으로 본다. 이 구간은 관례적 허용 범위를 이 연구에서 선택한 것이다.
  - 모든 조건의 결과를 보고한다. 기준이 되는 단일 조건은 두지 않는다.
- **3d. 보고 원칙**
  - (1) 현행 절차가 모든 조건에서 반증되지 않으면: 현행 CI를 본문에 두고, "가정한 자료생성과정 아래에서만 점검됨"이라고 명시한다.

  - 어느 경우든 모의실험 결과가 실제 자료에서의 타당성을 증명한다고 쓰지 않는다.

## 4. 사전추세 시나리오 분석 (S3) — 설계는 지금 고정

- **4a.** 동일 7품목·고정 대조군의 사전 궤적과 품목별 기울기를 제시한다(재분석 코드 재사용).
- **4b. 시나리오 계산** (강건 신뢰구간이 아님)
  - 품목별 상대 기울기 s_i: D_i(t) = Y_i(t) − mean_{j∈J_i} Y_j(t)를 t ∈ {b_i−4, …, b_i}에서 OLS로 회귀한 기울기. J_i는 이 5년 동안 모두 clean한 대조군으로 고정한다.
  - 가정한 편향: Bias_{i,e}(k) = k × s_i × [(g_i+e) − b_i]
  - 조정 추정치: θ(k) = θ − (1/10) Σ_{e=0..9} (1/N_e) Σ_{i∈I_e} Bias_{i,e}(k). 원 추정량과 같은 가중치를 쓴다.
  - k ∈ {0, 0.5, 1}. 추가로 θ(k) = 0이 되는 k(부호가 바뀌는 지점)를 보고한다.
  - 기울기 불확실성: 품목별 s_i의 OLS SE(자유도 3)를 함께 보고한다. s_i ± 1.96·SE를 넣은 범위는 "시나리오 범위"로만 표기한다.
- **4c.** Rambachan–Roth 방식(서지 확인 필요)은 사전·사후 계수와 공분산, 공통 기준시점을 요구한다. 품목별로 기준시점이 다르고 전환기간 공백이 있는 이 설계에 적용할 수 있는지는 **별도로 검토**한다. 검토 전에는 4b를 강건 신뢰구간이라고 부르지 않는다.

## 5. 보고 — 지금 가능 (Stata 실행은 사용자 환경)

- **5a. 기술통계**
  - Mean, SD, Min, Max, N(품목-연도), 품목 수를 보고한다.
  - 집단은 실제 기여 셀로 나눈다(`outputs/contributing_cells.csv`): 처리작물의 전체 clean 사전, 기준연도, 사용된 사후(e = 0..9) / 대조작물의 사용 셀, 전체 clean 셀(맥락용).
  - 원단위(ha, kg/10a, 톤)와 로그를 함께 보고한다. SD는 품목-연도 간 분산이며 효과의 SE가 아니다.
- **5b. 효과:** 계수, SE, 95% CI, p, 처리군집 7, 기여 대조군집 22, 추론 절차명.
- **5c. 표현**
  - θ는 "사후 0–9년 각 시점에서 측정한, 기준연도 대비 차이의 평균"이다. 기간 합계 효과가 아니다.
  - 비유의 결과를 "효과 없음"으로 쓰지 않는다.
  - 사전계수의 비유의를 평행추세의 증명으로 쓰지 않는다.
  - 높은 공동검정 p값 하나로 검정력이 낮다고 결론짓지 않는다.
- **5d.** Stata do-file은 결과 CSV만 읽는다. 실행 검증 전까지 "미실행"으로 표시한다.
