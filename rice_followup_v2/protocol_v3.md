## 1. 질문과 추정대상

- 질문: "벼 재해보험의 조기 제공(2009년)은 후기 시범지역(2011년)에 비해 시군의 벼 재배면적 변화에 영향을 주었는가?"
- 추정대상: 2009·2010년의 조기 제공 의도처리(ITT) 효과(로그 포인트)다. 가입 효과가 아니다.
- **DiD를 인과적으로 해석하려면 평행추세 가정이 필요하다.** 즉, 보험이 없었다면 두 집단의 ln 벼 면적이 같은 추세를 따랐어야 한다. 후기 시범지역도 무작위로 선정되지 않았으므로 이 가정은 보장되지 않는다. 사전 자료는 가정의 타당성을 점검하는 근거이며 가정을 입증하지 않는다.

## 3. 주 분석 (A + 2)

**추정량 A.** 다음 TWFE 모형을 쓴다.

ln(area_it) = α_i + γ_t + β·D_it + u_it, 여기서 D_it = 1[2009년 집단]·1[t ≥ 2009].

- 기간은 2000–2010년이고, 시군 가중치는 모두 같다.
- 균형패널이므로 β는 다음과 같다: [처리집단의 (2009–10 평균 − 2000–08 평균)] − [비교집단의 같은 차이].

**주 검정 2: 귀무가설을 부과한 wild cluster bootstrap-t (WCR).**
- H0는 β=0이다. β=0을 부과한 제약모형 ln(area) = α_i + γ_t + u에서 잔차 ũ와 적합값을 구한다.
- 재표집 단위는 시군(군집 26개)이다. y* = 적합값 + v_g·ũ_it로 만든다.
- v_g는 Webb 6점 분포(±√1.5, ±1, ±√0.5, 각 확률 1/6)를 따른다.
- 반복은 9,999회이고, 난수는 numpy `default_rng(20261004)`로 만든다. 한 번 뽑은 가중치 행렬을 모든 β0 검정에 공통으로 쓴다.
- 각 반복에서 비제약 β*와 CR1 SE*로 학생화 t* = (β* − β0)/SE*를 계산한다.
- 관측 t는 (β̂ − β0)/SE_CR1이다. 양측 대칭 p값은 mean(|t*| ≥ |t|)이다.
- **주 95% 구간은 같은 WCR 검정을 뒤집어 만든다.** 즉 H0: β=β0의 WCR p값이 0.05 이상인 β0의 집합이다. 격자 탐색(β̂ ± 8·SE_CR1, 간격 SE/200)으로 경계를 찾고, 이분법으로 1e-6까지 좁힌다.
- **구현 검증:**
  - 같은 자료에서 `fwildclusterboot::boottest`(type="webb", impose_null=TRUE, B=9999)와 p값을 대조한다. 난수가 다르므로 몬테카를로 오차 범위 안에서 일치하는지 본다.
  - 이 패키지를 설치하지 못하면 미대조로 기록한다.
- 보조 추론은 CR1 SE(G/(G−1)·(N−1)/(N−K) 보정)와 t(25) 검정이다.
- 주 결과표에는 **β̂, CR1 SE, CR1 t(25) p값, WCR bootstrap p값, WCR bootstrap 95% 구간**을 각각 이름을 붙여 적는다. 본문의 주 p값과 주 구간은 WCR 값이다.
- **무작위화 추론은 하지 않는다.** 조기·후기 배정이 무작위였다는 근거가 없고, 여러 p값 가운데 하나를 고르는 구조를 피하기 위해서다.
- 해석에 참고할 MDE는 (t_{0.975,25} + t_{0.80,25})·SE_CR1로 계산한다.

- (g) 보조 결과변수: ln(벼/경지)와 ln(벼/논)에 추정량 A를 적용한다.

## 5. 해석 규칙

- 유의 여부와 관계없이 주 결과(A, WCR p값과 구간) 하나를 보고한다.
- 사전 경로에서 비교 가능성이 부족하다는 증거가 나오면 인과 주장을 낮춘다. 이 증거는 (b)의 결합검정 기각, 체계적인 사전 계수 패턴, (c)의 경로를 말한다.
- 비유의 결과를 "효과 없음"으로 쓰지 않는다. MDE는 동등성 한계가 아니다.
- WCR bootstrap도 군집이 적을 때 항상 정확한 것은 아니다. 처리 17곳, 비교 9곳으로 균형이 맞지 않다는 점을 함께 적는다.
