# 프로토콜 v2 부록 1: 사전 가짜처리 추적과 검토 의견 반영

작성: 2026-10-04. 이 부록은 아래 진단을 **실행하기 전에** 커밋한다. 이미 본 결과는 다음과 같다.

- 주 SDID 결과: 0.0061, SE 0.0131.
- 2006–08년 가짜처리: 0.0436, SE 0.0126, p=0.00055.
- 연도별 격차.
- 처리 단위 leave-one-out.

## 검토 의견과 반영 방식

1. **주 결과를 인과적 결론으로 채택하지 않는다.** 가짜처리 결과가 설명되기 전까지 TOST 통과 여부와 관계없이 "보험 효과가 ±5% 이내"라고 쓰지 않는다. REPORT의 해석 절을 이에 맞게 수정한다.
2. **사전 시간가중치를 명시한다.** 2007년 0.525, 2008년 0.475이고, 2000–2006년은 0이다. 긴 사전기간 전체가 잘 맞았다는 근거가 아니다.
3. **논산+계룡은 처리 상태가 섞인 단위다.** 원 프로토콜의 "효과가 0 쪽으로 희석된다"는 서술은 보장되지 않으므로 철회한다. 계룡 쪽 효과의 부호나 파급을 알 수 없기 때문이다. 다음 두 민감도를 별도로 보고한다.
   - D4a: 논산+계룡 제외. 처리 17곳, 비교 121곳.
   - D4b: 합산 단위 모두 제외. 처리 17곳, 비교 119곳.
4. **결과변수 서술을 바꾼다.** ln(벼/경지 계)는 새로운 결과변수다. 경지면적도 보험의 영향을 받을 수 있으므로, 도시화를 제거한 벼 면적 효과로 서술하지 않는다.
5. **SC에는 jackknife SE를 계산하지 않는다.** 패키지 문서가 SC에는 권장하지 않기 때문이다. SC는 bootstrap과 placebo SE만 보고한다.

## 가짜처리 추적 진단 (모두 기술적 진단, 효과 추정 아님)

가짜처리 설정은 원 프로토콜과 같다. 2000–05년이 사전, 2006–08년이 가짜 사후이며, 처리 18곳 대 비교 121곳, 결과변수는 ln 비중이다.

- **D1 단위별 분해.** 가짜처리 SDID의 가중치(ω, λ)를 고정하면 τ = (1/N1)Σ_i d_i − c다. 여기서 d_i = Ȳ_i,post − λ'Y_i,pre이고, c는 ω로 가중한 비교 단위의 같은 양이다. 다음을 보고한다.
  - 처리 단위별 d_i − c와 연도별(2006, 2007, 2008) 값.
  - 비교 쪽 기여 ω_j(…)의 상위 단위.
  - 가짜처리의 시간가중치 λ.
- **D2 성분 분해.** 같은 고정 가중치를 ln 벼 면적과 ln 경지면적에 각각 적용한다(τ_share = τ_rice − τ_farmland, 항등식). 가짜처리의 상승이 처리지역 벼 면적의 상대 증가에서 왔는지, 경지면적의 상대 감소에서 왔는지 구분한다.
- **D3 자료 단절.** 다음을 점검한다.
  - (a) 두 원자료에서 연도별로 값이 있는 시군 행의 수. 2006년 계룡·증평 분리처럼 행 구성이 바뀌는 해가 있는지 본다.
  - (b) 시군 합계와 시도 합계의 연도별 비율. 집계 범위가 바뀌었는지 본다.
  - (c) 2000–2008년 처리지역과 비교지역의 연간 로그 변화. 처리 단위 중 |Δ|>0.10인 단위·연도를 목록으로 만든다.
  - (d) 연도별 격차의 전년 대비 변화와 그 jackknife SE(주 분석 가중치 고정). 상승이 특정 연도에 몰려 있는지 본다.
- **D4 논산+계룡 민감도.** 위 3번의 D4a·D4b 각각에 대해 주 SDID와 2006–08 가짜처리를 jackknife SE로 계산한다.
- **해석 규칙.** 진단은 원인 후보를 찾기 위한 것이다. 진단 결과를 보고 특정 지역·연도를 제거한 표본을 새 주 결과로 삼지 않는다. 자료 단절이 독립적으로 확인되면 그때 별도 부록으로 처리한다.
