## 이번에 알게 된 사항

- 동일가중 생산 비교값 0.019883 → 2003–2007년 고정 면적가중 −0.092973.
- 두 봄 계열 제외: 동일가중 −0.073679 → 면적가중 −0.185293.
- 이것은 유의성 개선이 아니라 추정대상 변경입니다. 새 가중치의 SE·CI·p는 계산하지 않았습니다.
- 양파의 원 비교 생산값은 0.405551, 고추는 −0.651345입니다. 품목들의 상쇄를 그림과 기여값으로 설명했습니다.
- 평균·SD는 실제 기여 셀의 기술통계입니다. 평균의 SE를 SD/√N으로 계산해 독립관측처럼 취급하지 않았습니다.

## 실행 및 검증 범위

실행: 직접 비교값 재구축, 기술통계, 고정구성 사전추세, 기존 핵심 민감도와 품목 누락 비교의 점추정 재현, 새 면적가중 점추정, Python 그림, Word 생성·렌더링.

검증: 56개 수치·표본 구성 대조 통과. 세 결과변수 × 두 대조군 × 일곱 품목 × 열 시점의 420개 직접 비교값이 기존 결과와 일치합니다. 결과는 `outputs/validation.json`에 기록합니다.

미실행: 새 bootstrap, 새 모의실험, Stata, 원 KOSIS 파일의 재구축, 공식 기관의 정의·시점 확인, 과수·가격의 전체 추론 재실행. 기술통계표의 근거 패널은 기존 자료와 같으므로 원자료의 독립 감사가 아닙니다.

기존 원고의 p·구간은 서로 다른 난수 실행값이 섞이지 않도록 9월 30일 `original_multiplier` 결과로 통일했습니다. 이는 검정의 타당성이 입증되었다는 뜻이 아닙니다. 표 5.3에 진단용 수치로 표시했습니다.

## 원고와의 차이

- 원본 장의 질문·자료·주요 비교식과 과수·가격·벼의 범위는 유지하되, 새 설명 순서에 맞게 절과 표·그림 번호를 바꿨습니다. 원본 파일은 수정하지 않았습니다.
- “누적 10년 효과”, “한 품목에 의존하지 않음”, “비유의하므로 효과/도덕적 해이가 없음”처럼 잘못 읽힐 표현을 배제했습니다.
- 과수·가격의 기존 숫자를 삭제해 숨기지 않고 보조 분석으로 남겼습니다. 기존 TWFE·imputation은 검증된 대체 주분석으로 채택하지 않았으며 원 저장소에 보존했습니다.
- 상세 가입률·수입보험 중첩 연도 및 Han의 톤 단위 계수 등 이번에 원문 재검증하지 않은 주변 수치는 본문에서 덜어냈습니다. 해당 사실이 필요하면 Liner가 원문·쪽수를 확인한 뒤 추가해야 합니다.
- 기존 우수논문 PDF를 새로 확인하지 않은 상태이므로 “우수논문과 완전히 같은 양식”이라고 주장하지 않습니다. A4·학위논문 본문·표·그림·수식 형식으로 정리했습니다.
